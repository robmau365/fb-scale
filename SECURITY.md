# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the Facebook Monetization Toolkit, please create an issue with the "security" label. We take all security vulnerabilities seriously and will respond to confirmed vulnerabilities.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Security Best Practices

1. Always use environment variables for sensitive data
2. Keep your API keys secure and never commit them to version control
3. Regularly update dependencies to patch security vulnerabilities
4. Use HTTPS for external API communication
5. Implement proper input validation and sanitization
